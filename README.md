# Best For Service — от мастера до инженера автоматизации

Всё внутри: `index.html` + папка `images/` (фото, видео и фон сайта).

- Фон всего сайта — видео из мастерской: на компьютере `images/bg-wide.mp4` (мягкий фон) + `images/workshop.mp4` в рамке на главном экране, на телефоне `images/workshop.mp4` во весь экран.
- Фото с женой — `images/family-hq.jpg` (блок «Кто я»).

## Как загрузить на GitHub
1. Создайте репозиторий (например, `best-for-service-site`).
2. **Add file → Upload files** → перетащите `index.html` и папку `images` целиком → **Commit changes**.

## Как включить сайт
**Settings → Pages → Branch: main, папка / (root) → Save.** Через пару минут сайт откроется по адресу вида `https://<логин>.github.io/best-for-service-site/`.
